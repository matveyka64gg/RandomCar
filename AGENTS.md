## О проекте

3D-гонка «RandomCar». Одна трасса, 3 круга, 4 машины: игрок и 3 ИИ. Случайные события на трассе: 6 плохих и 2 хороших, все с предупреждением. Ползунок «Хаос» (выкл / умеренно / много) меняет только частоту событий.

Один компьютер, один игрок, без сети. Сетевой режим не трогаем. Игра для себя, друзьям не раздаётся.

## Правила игры (их нельзя нарушать)

Это правила честности, по ним проверяются тесты этапа 2.

- Два тяжёлых события подряд не выпадают. Тяжёлые: ракеты и танки.
- Предупреждение каждого события не короче 1.5 с, по умолчанию 2 с. Эффект стартует только после окончания предупреждения.
- Цель события выбирается равновероятно из всех 4 машин. Позиция в гонке не учитывается, отстающего не выбираем.
- Событие не решает гонку: замедление не длиннее 1.5 с, буст 2 с, отбрасывание без урона и без выбывания, постоянных изменений нет.
- Зона опасности не шире половины дороги. Прицел ставится в текущую позицию машины со сдвигом ±1 м.
- Хаос меняет только частоту. Выкл: событий нет. Умеренно: примерно каждые 20–30 с. Много: примерно каждые 8–12 с.
- Веса событий лежат в одном месте (ScriptableObject или константы в `EventDirector.cs`). Суммарный вес плохих и хороших равен (50/50).
