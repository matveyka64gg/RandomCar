# RandomCar — Beta 0.1

Аркадная 3D-гонка на Unity 6 с безумными случайными событиями. Четыре карты («Холмы Рандома», «Город», «Пустыня», ночной «Тель-Авив»), десять машин с обвесами, окраской и наклейками, одиночный режим с ИИ, локальная сетевая игра и своя музыка: от червей и ракет до трамплинов, ускорителей и шоу вроде прыгающего смайлика.

**Статус:** первая публичная бета. Возможны ошибки, баланс и производительность ещё настраиваются.

## Скачать и установить

Готовые сборки — в разделе **Releases** этого репозитория:

| Платформа | Файл | Требования |
|---|---|---|
| Windows | `RandomCar-Windows.zip` | Windows 10/11, 64-бит |
| Android | `RandomCar-Android.apk` | Android 8.0+, 64-битный процессор |

### Windows

1. Скачайте `RandomCar-Windows.zip` и распакуйте архив **целиком** в отдельную папку (например, `C:\Games\RandomCar`).
2. Запустите `RandomCar.exe`. Папку `RandomCar_Data` и файлы рядом с ней не удаляйте и не переносите отдельно от `.exe`.
3. При первом создании сетевого лобби Windows спросит разрешение брандмауэра. Без него друзья не подключатся.

Обновление: распакуйте новую версию в новую папку. Свою музыку и наклейки из папки `UserContent` рядом со старой игрой перенесите вручную (см. раздел «Своя музыка»).

### Android

1. Скачайте `RandomCar-Android.apk` на телефон.
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите (для браузера или файлового менеджера, которым открываете APK).
3. Установите и запустите RandomCar.

APK подписан отладочным ключом сборки: это тестовая раздача, а не версия для Google Play.

## Как играть

Стартовая комплектация: **0 кредитов** и одна машина — «Искра». Кредиты начисляются за гонки (чем выше место и больше обогнанных соперников, тем больше; за новый рекорд трассы — бонус). На них покупаются остальные машины, детали обвеса, диски, шины и краски. Реальных денег в игре нет.

- **Трассы:** «Холмы Рандома», «Город», «Пустыня», «Тель-Авив».
- **Гараж:** машины, характеристики, обвесы, диски, шины, окраска, наклейки (в том числе свои картинки), сборки (до 6 на машину).
- **Хаос** (в меню): выключен / умеренно / много / **безумие** (стандарт) / **абсурд**. Чем выше уровень, тем чаще и сильнее события.
- **Бонусы:** ящики «?» на трассе; один бонус в запасе. Применить — клавиша E (на геймпаде B). После возврата на трассу 2 секунды защиты.
- **Опасности и польза:** красная плашка и красное кольцо на дороге — опасность, уходите с полосы. Бирюзовые — польза, заезжайте. События ставятся впереди вас и ждут, пока вы подъедете.
- **Полигон испытаний** (пункт главного меню): площадка, где можно запустить любое событие игры на любой машине.

### Управление на клавиатуре

| Действие | Клавиши |
|---|---|
| Газ / тормоз (на месте — задний ход) | W / ↑, S / ↓ |
| Руль | A / D или ← / → |
| Ручной тормоз | Пробел |
| Бонус | E (меняется в настройках) |
| Камера: вид сзади / из салона | C (меняется в настройках) |
| Осмотреться вокруг машины | зажать правую кнопку мыши |
| Приблизить / отдалить камеру | колесо мыши |
| Пауза | Esc или P |
| Заново | R |
| Музыка: предыдущий / пауза / следующий | B / M / N |

### Геймпад

Левый стик — руль, триггеры — газ и тормоз, A — ручной тормоз, B — бонус, Y — вид, Start — пауза.

### Телефон (Android)

Экранные кнопки: ◀ ▶ руль, ГАЗ, ТОРМОЗ, РУЧНИК, БОНУС, ВИД, II — пауза. Кнопка «Назад» Android — назад или пауза. Экранные кнопки можно включить и на ПК: «Настройки → Экранные кнопки». Геймпад также поддерживается.

## Своя музыка

Игра не содержит общей музыки: её можно добавить самим. Ваши треки проигрываются в разделе **«Моя музыка»** главного меню; там же выбирается источник: вся музыка, встроенная или только своя.

**Windows**
- Положите файлы `.ogg`, `.mp3` или `.wav` в папку `UserContent\Music` рядом с `RandomCar.exe`. Игра найдёт их при запуске и при открытии раздела.
- Или откройте «Моя музыка» → «Добавить музыку» — откроется окно выбора файлов Windows (можно выбрать несколько).

**Android**
- «Моя музыка» → «Добавить музыку» — откроется системный выбор файлов. Игра не просит доступа ко всему хранилищу и сохраняет копию у себя.

**Что важно знать**
- «▶» — слушать трек, «×» — убрать из библиотеки. Файл в папке `UserContent\Music` при этом не удаляется.
- Копии, сделанные игрой, хранятся в `%USERPROFILE%\AppData\LocalLow\DefaultCompany\RandomCar\UserContent` (на Android — в личной папке приложения) и сохраняются при обновлении игры.
- Один и тот же файл под разными именами не добавляется дважды.

Свои картинки для наклеек — гараж → наклейки → библиотека → «Добавить наклейку» (PNG или JPEG, до 8 МБ и 4096×4096). Картинки хранятся только на вашем устройстве и никуда не отправляются.

## Игра по сети

Сетевая игра работает напрямую между компьютерами или телефонами без серверов, аккаунтов и интернет-подключения. Удобнее всего — через Radmin VPN, Hamachi или одну локальную сеть.

1. Один игрок выбирает «Сетевая игра» → «Создать лобби» (порт по умолчанию 7777) и сообщает друзьям адрес из списка в лобби: `26.x.x.x` — Radmin VPN, `25.x.x.x` — Hamachi, `192.168.x.x` / `10.x.x.x` — локальная сеть.
2. Остальные вводят адрес («IP» или «IP:порт»), нажимают «Подключиться», выбирают машину и «Готов».
3. Хост выбирает трассу, число соперников-ИИ и уровень Хаоса и нажимает «Старт».

До 6 участников на решётке (игроки и ИИ). У всех должна быть одна и та же версия игры. Свои картинки-наклейки и музыка другим игрокам не передаются.

## Разработка

Проект — Unity 6000.6.7f1 (URP, Input System, Netcode for GameObjects). Открыть `RandomCar` в Unity Hub, сцена для игры — `Assets/Scenes/Game.unity`.

| Что | Как |
|---|---|
| Тесты | Test Runner → EditMode, или `unity command test run --mode EditMode` |
| Сборка Windows | меню `RandomCar/Build Windows (Beta)` → `Builds/Windows/RandomCar.exe` |
| Сборка Android | меню `RandomCar/Build Android APK (Beta)` → `Builds/Android/RandomCar.apk` (нужны модули Android Build Support, SDK и NDK, OpenJDK; IL2CPP, ARM64) |
| Модели машин и карт | скрипты Blender в `Tools/Blender` (запуск через `blender_client.py`, см. `AGENTS.md`) |
| Пересборка карт | `RandomCar/Build All` пересоздаёт все сцены карт; отдельно — `CityMapBuilder.Build()`, `HillsMapBuilder.Build()` и др. |
| Проверка сборки без человека | `RandomCar.exe -screen-fullscreen 0 -rc-race -rc-map City -rc-chaos 1 -rc-fpslog -rc-exit -rc-norecord -logFile out.log` |

Скриншоты редактора: `py -3 -I Tools/Unity/shot.py out.png` (путь к Unity CLI — из `PATH` или из переменной окружения `UNITY_CLI`).

Подробности для разработки — в `AGENTS.md`, стиль — в `Docs/ArtDirection.md`, события — в `Docs/EventLibrary.md`, планы и статус — в `Docs/Roadmap_v3.md`.
